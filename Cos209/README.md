This repo contains example JavaScript files demonstrating ECMAScript 6 concepts:
1. Classes
2. Arrow Functions
3. Variables (let/const)
4. Array Methods
5. Destructuring
6. Modules (ES modules)
7. Ternary Operators
8. Spread Operators

To run the module example, use Node.js v14+ with `"type": "module"` in package.json or run `node --experimental-modules main.mjs`.
